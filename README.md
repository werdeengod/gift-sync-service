# Gift Sync Service

Сервис отслеживает изменения подарков (gifts) в Telegram и своевременно уведомляет об этом внешние системы.
## 📋 Описание

1. Получение данных: синхронизирует подарки из Telegram (MTProto), отслеживая их появление и изменения.
2. Хранение: сохраняет актуальное состояние подарков в PostgreSQL.
3. Уведомление внешнего мира: при любом изменении публикует событие в RabbitMQ. Гарантирует, что каждое событие будет доставлено ровно один раз (идемпотентность через паттерн Outbox).
4. Фоновая обработка: выполняет фоновые задачи (синхронизацию, публикацию событий, ретраи) через собственный воркер, который устойчив к сбоям: повторяет неудачные операции с экспоненциальной задержкой и джиттером, контролирует таймауты, умеет откатываться на fallback-сценарии, масштабируется горизонтально и корректно завершает работу (graceful shutdown).
## 🏗 Архитектура

Проект построен на **гексагональной архитектуре** (Hexagonal/Ports & Adapters) с элементами Clean Architecture по методологии DDD:

| Слой | Назначение | Содержит                                                               |
| :--- | :--- |:-----------------------------------------------------------------------|
| **Domain** | Бизнес-логика | Entities, Exceptions, Value Objects, Domain Events, Ports (интерфейсы) |
| **Application** | Сценарии использования | Use Cases, DTO                                                         |
| **Adapters** | Входящие адаптеры | REST API, Workers                                                      |
| **Infrastructure** | Исходящие адаптеры | PostgreSQL, RabbitMQ, Telegram API, Worker Engine                      |
